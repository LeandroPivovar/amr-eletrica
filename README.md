# AMR Eletricidade e Serviços - site institucional

Site one-page da **AMR Eletricidade e Serviços**: serviços elétricos e hidráulicos, pequenos reparos e marido de aluguel em Fortaleza - CE.

## Estrutura

```
index.html   # página única (hero, sobre, serviços, depoimentos, mapa, FAQ)
styles.css   # estilos (grafite + dourado da marca, tema claro/escuro automático)
script.js    # menu mobile, header ao rolar, animações de entrada, faixa de depoimentos, FAQ
assets/      # logo, favicon e fotos
```

Sem build: HTML, CSS e JS puros. Publique a pasta em GitHub Pages, Netlify, Vercel ou hospedagem comum.

- **Depoimentos** são exemplos. Substitua por avaliações reais de clientes.
- **Logo**: recortado de um print do WhatsApp (baixa resolução). Troque `assets/logo-amr.png` e `assets/favicon.png` pelo arquivo original.
- **Horário**: o perfil mostra 09:00 - 18:00 na quinta-feira. O site diz "das 9h às 18h" e o JSON-LD assume segunda a sexta. Confirme os dias.
- **Lista de serviços** (chips) e **FAQ**: montados a partir de "serviços elétricos e hidráulicos, pequenos reparos e marido de aluguel". Confirme o que a empresa faz e não faz.
